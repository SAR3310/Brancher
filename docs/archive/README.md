# Arsip dokumentasi

Folder ini berisi laporan sesi kerja dan ringkasan status dari pengembangan awal Brancher.

**Jangan dijadikan sumber acuan.** Klaim seperti "production ready", "100%", atau "Stability ✅" di sini tidak diverifikasi ulang. Beberapa bug yang sudah diperbaiki (backend crash saat start, login gagal karena field `identifier` vs `email`) tidak tercatat di laporan-laporan ini.

Dokumentasi yang aktif ada di `README.md`, `DEVELOPMENT.md`, `TROUBLESHOOTING.md`, dan `docs/`. Riwayat perubahan ada di `CHANGELOG.md`.
